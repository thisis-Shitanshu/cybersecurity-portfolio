## Target roles

- **Security Data Engineer:** Build and operate the security data lake and streaming pipelines for logs, metrics, and alerts.
- **Detection Engineer (ML):** Create features and models for detection and prioritization, measure drift and false positives.
- **Security Analytics Engineer:** Develop queries, dashboards, and KPIs that drive investigations and executive reporting.
- **SOC Automation Engineer:** Automate playbooks, enrichment, and triage using scripts, jobs, and CI.
- **Threat Intelligence ML Engineer:** Parse and learn from TI feeds and text to generate usable indicators and context.
- **Cloud Security Data Platform Engineer:** Secure and monitor cloud data paths, configure controls, and enforce least privilege.

---

## Core responsibilities

**Data engineering**

- Ingest and normalize telemetry from endpoints, network, cloud, and apps.
- Model security events and entities, manage schemas and quality checks.
- Build streaming jobs for enrichment, correlation, and routing.
- Control access and encryption for data at rest and in transit.

**ML engineering**

- Create features from raw logs, labels from alerts and tickets, and training sets.
- Train and evaluate detection and prioritization models with clear metrics.
- Monitor drift, retrain safely, and version models and data.
- Guardrails for misuse: bias checks, safe thresholds, and human-in-the-loop.

**Operations**

- Write runbooks and automate responses for common incidents.
- Track SLAs for ingestion, model freshness, and alert latency.
- Document decisions and lessons in an incident journal.
