## Featured work

### [Kubeflow Spark Operator Supply-Chain Security Analysis](showcases/kubeflow-spark-operator-security-audit/)

Investigated the security boundary of the Kubeflow Spark Operator controller image.

The work included:

- tracing vulnerabilities inherited from the Apache Spark base image
- comparing the Spark base image with the final Spark Operator image
- identifying shaded JVM dependencies inside Hadoop artifacts
- testing a controlled Jackson remediation
- validating runtime compatibility with Spark 4.0.4
- documenting security guidance for an upstream Kubeflow contribution
